# OpsTrack

Локальный DevOps / Network Study Tracker, построенный по трём предоставленным источникам. Интерфейс работает без backend: прогресс, переносы, заметки, настройки и пользовательские элементы сохраняются в `localStorage` браузера.

## Запуск

Дважды щёлкните `START_OPSTRACK.bat`. Откроется `http://127.0.0.1:4173/`. Окно сервера нужно оставить открытым на время работы; для остановки нажмите `Ctrl+C`.

Можно также открыть `dist/index.html` напрямую, но локальный сервер обеспечивает более предсказуемое хранение данных в браузере.

## Резервная копия

На странице «Настройки» нажмите «Экспортировать». Файл `devops-tracker-backup-ГГГГ-ММ-ДД.json` содержит отметки, даты, заметки, пользовательские задачи и настройки. Для восстановления выберите «Импортировать» и укажите этот JSON. Перед применением структура и связи проверяются.

## Архитектура

- `dist/index.html` — оболочка одностраничного приложения.
- `dist/css/main.css` — тёмная/светлая темы и адаптивная раскладка.
- `dist/js/model.js` — даты, прогресс, долги, зависимости, streak и рекомендации.
- `dist/js/storage.js` — хранение, миграция каталога, импорт и экспорт.
- `dist/js/app.js` — маршруты, интерфейс и все действия пользователя.
- `dist/data/curriculum.js` — встроенный полный учебный каталог.
- `data/` — структурированные результаты анализа исходных материалов.
- `scripts/` — воспроизводимая сборка объединённого каталога.
- `tests/model.test.js` — проверки расчётов и целостности backup.
